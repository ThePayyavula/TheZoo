

# Feedback

### Things people like on workout tracker apps
- Easy to update new information
- Showing accurate macros, micro nutrients, & tracks them reliably
- User-submitted food database
- Something which keeps the site fresh
- Simple, responsive UI
- Easily displaying progress
- Day streaks to keep you coming back

### Things that make people stop using workout tracker apps
- Overly cluttered UI
- Inaccurate or otherwise unreliable information
- Poorly functioning features
- Nothing new or exciting on the app
	- Once people find a routine, they can keep it going as is


# Requirements/User Stories
1. As a User, I want to easily update my daily food, workout logs, and weight so that I can track my progress
2. As a User, I want to easily view my end goals so that I make sure I'm progressing
3. As a User, I want to be able to reset my target weight & goals so that I can continue improving
4. As a User, I want to easily upgrade and see my animals so I can visualize my progress

-----

# Tasks for Each User Story
1. As a User, I want to easily update my daily food, workout logs, and weight so that I can track my progress
	1. Ability to update food
	2. Ability to update workout
	3. Ability to update weight
	4. Ability to add previously added food
	5. Simplified UI for easily updating information
2. As a User, I want to easily view my end goals so that I make sure I'm progressing
	1. Display end goals
	2. Simplified UI for displaying end goals
3. As a User, I want to be able to reset my target weight & goals so that I can continue improving
	1. Ability to reset target weight goals
	2. Simplified UI for being able to reset goals
4. As a User, I want to easily upgrade and see my animals so I can visualize my progress
	1. Display animals in an easy way
	2. Simplified UI to be able to see it
